# Phase advance prompts (copy-paste)

After you **look at the site** for the current phase, send **one** of these. You do not need a long message.

The agent treats **GO**, **next**, **looks good**, and **continue** as the same: current phase approved, start the next phase in order.

---

## Universal (use every time)

```
GO — Phase [N] looks good. Start the next phase. Follow IMPLEMENTATION.md, reference-first, ELI5 any step I must click.
```

Short version:

```
next
```

If something is wrong:

```
CHANGE: [what to fix]
```

If you want to pause:

```
HOLD
```
